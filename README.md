Vidyavana Computer Educational Institute Website

A modern full-stack educational institute website built using Next.js and Django REST Framework. The platform provides information about courses, admissions, enquiries, reviews, FAQs, and includes an AI-powered chatbot for student assistance.

 Features

- Responsive and modern UI
- Course management
- Student enquiry system
- Contact form
- Testimonials & Reviews
- Frequently Asked Questions (FAQ)
- AI Chatbot Assistant
- Dashboard & Analytics
- Notifications
- Authentication APIs
- RESTful Backend APIs

Installation

Clone Repository

bash
git clone https://github.com/MubeenaDevep/vidyavana-website.git

Backend Setup

bash
cd vidyavana-backend

python -m venv .venv

Windows
.venv\Scripts\activate

pip install -r requirements.txt

python manage.py migrate

python manage.py runserver

Backend runs at
http://127.0.0.1:8000/

Frontend Setup
bash
cd vidyavana-frontend

npm install

npm run dev

Frontend runs at
http://localhost:3000/
